# 自动审核功能使用说明

## 功能概述

自动审核功能是HPIMS系统的核心功能之一，通过Python智能算法对处方进行多维度安全性评估，包括：
- 药品兼容性检查
- 用量合理性验证
- 药品相互作用检测
- 患者安全性评估

## 使用流程

### 1. 医生端 - 提交自动审核

**位置**: 医生工作台 → 我的处方

**操作步骤**:
1. 创建处方后，处方状态为"未审核"
2. 在处方列表的"操作"列，点击"自动审核"按钮
3. 系统会调用Python审核服务进行自动审核
4. 审核完成后，会自动弹出审核结果对话框，显示：
   - 审核结果（通过/警告/拒绝）
   - 审核得分（0-100分）
   - 发现的问题
   - 审核建议

**审核结果说明**:
- **通过** (绿色): 得分100分，无问题，可以直接进入发药流程
- **警告** (黄色): 得分75-99分，存在一定风险，建议人工审核
- **拒绝** (红色): 得分≤75分，存在严重问题，建议驳回

### 2. 药师端 - 查看和重新审核

**位置**: 药师工作台 → 处方管理

**功能**:
1. **查看自动审核结果**: 
   - 点击"查看"按钮，在处方详情中可以看到完整的审核历史
   - 审核历史表格中会显示所有审核记录（自动审核和人工审核）

2. **重新自动审核**:
   - 对于"未审核"或"已拒绝"状态的处方，可以点击"自动审核"按钮重新审核
   - 适用于处方修改后需要重新审核的情况

3. **人工审核**:
   - 点击"人工审核"按钮
   - 系统会自动加载最新的自动审核结果，并预填充到审核表单中
   - 药师可以基于自动审核结果进行人工复核
   - 可以修改审核结果、得分、问题描述和建议

4. **审核详情查看**:
   - 在审核历史表格中，点击"查看详情"按钮
   - 可以查看完整的审核信息，包括：
     - 审核类型（自动/人工）
     - 审核结果和得分
     - 发现的问题
     - 审核建议

## 注意事项

1. **Python服务必须运行**: 
   - 自动审核功能依赖Python审核服务
   - 确保Python服务在 http://localhost:5000 正常运行
   - 可以通过 http://localhost:5000/health 检查服务状态

2. **审核结果延迟**:
   - 自动审核需要1-2秒处理时间
   - 提交审核后，系统会自动刷新列表并显示结果

3. **审核历史**:
   - 所有审核记录都会保存到数据库
   - 可以在处方详情中查看完整的审核历史

4. **药品知识库**:
   - 审核准确性依赖于药品知识库的完整性
   - 建议在药品管理中添加药品的适应症、禁忌症和相互作用信息

## 常见问题

**Q: 点击自动审核后没有反应？**
A: 检查Python服务是否运行，查看浏览器控制台是否有错误信息。

**Q: 审核结果一直显示"审核中"？**
A: 可能是Python服务处理超时，检查Python服务日志，或尝试重新审核。

**Q: 审核得分总是100分？**
A: 检查药品知识库数据是否完整，特别是推荐剂量、禁忌症等字段。

**Q: 如何查看详细的审核问题？**
A: 在审核历史表格中点击"查看详情"按钮，可以查看完整的问题描述和建议。
